# 解决开机后黑屏只显示鼠标的问题
---
## 步骤一
1. 按下 `Win+Ctrl+Shift+B` 屏幕可能会闪烁 或 有 **哔** 声
2. 没反应下一步
---
## 步骤二
1. 按下 `Ctrl+Shift+Esc` 或 `Ctrl+Alt+Delete` 打开 **任务管理器**
2. 点击右上角 **运行新任务**
3. 输入 `explorer.exe` 勾选 **以系统管理权限创建此任务** 点击 **确定**
4. 不管屏幕是否恢复正常,在 **进程列表** 中找到 `Windows 资源管理器` 右键选择 **重新启动**
5. 未解决下一步,已解决去到 **步骤四** 完成完整修复
---
## 步骤三
1. 长按电源键强制关机,等待关机后按下电源键打开
2. 屏幕出现任意画面(除了显示器休眠界面),立即再次长按电源键强制关机
3. 重复上述步骤3次
4. 第4次开机时,屏幕下方应该会显示 **"正在准备自动修复"** 或 **"诊断你的电脑"**
5. 等待进入一个全蓝色的 **"选择一个选项"** 界面
> 点击 **疑难解答 → 高级选项 → 启动设置 →** 点击右下角的 **重启**  
重启后,屏幕会弹出一个菜单,按键盘上的 **4** 或 **F4** ,选择 **"启用安全模式"**
6. 如果成功进入安全模式,直接点击开始菜单的重启按钮,大概率就好了
7. 不管好没好都继续下一步进行完整的修复
---
## 步骤四
1. 按下 `Ctrl+Shift+Esc` 或 `Ctrl+Alt+Delete` 打开 **任务管理器**
2. 点击右上角 **运行新任务**
3. 输入 `cmd` 勾选 **以系统管理权限创建此任务** 点击 **确定**
4. 依次输入下面的命令, **大小写要注意** (输完第一条回车,等执行完成再输第二条/第三条)
~~~
sfc /scannow
~~~
~~~
Dism /Online /Cleanup-Image /RestoreHealth
~~~
~~~
shutdown /r /t 0
~~~
